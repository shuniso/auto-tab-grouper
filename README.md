# Auto Domain Grouper

同一ドメインのタブを自動でグループ化するChrome拡張機能（Manifest V3）。

## 機能

- 同じドメインのタブが2つ以上あれば色分けしてグループ化（ウィンドウ単位・複数ウィンドウ対応）
- ポップアップでドメインごとに自動グループ化のON/OFFを切り替え
- グループの色・開閉状態を記憶
- ローカルファイル（`file://`）はトグルに関係なく専用グループにまとめる
- タブが1つに減ったグループは解除する

### Chromeの保存済みタブグループについて

Chromeはタブグループを自動保存し、グループのタブを閉じても「閉じたグループ」として残す（解除した場合は保存も削除される）。
拡張APIからは保存済みグループを削除できないため、本拡張は次の方法で増え方を抑える。

- 1タブになったグループは解除し、最後のタブを閉じても保存済みグループとして残らないようにする
- ブラウザ再起動後などは新規作成せず、同じ名前の既存グループを再利用する

ウィンドウやブラウザを閉じた時に開いていたグループは保存済みとして残るので、不要なものはChromeの「タブグループ」メニューから削除する。

## インストール

1. このリポジトリをクローン
2. `chrome://extensions/` を開き「デベロッパーモード」を有効化
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択

## テスト

依存ゼロ（Node.js標準テストランナー）: `node --test`
